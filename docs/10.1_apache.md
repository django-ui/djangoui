# Running Apache docker

Open http and https port on redhat

```
sudo firewall-cmd --zone=public --permanent --add-service=https
sudo firewall-cmd --zone=public --permanent --add-service=http

```

docker pull httpd:2.4


## Create a Dockerfile in your project

```
FROM httpd:2.4
COPY ./public-html/ /usr/local/apache2/htdocs/
#COPY ./my-httpd.conf /usr/local/apache2/conf/httpd.conf
```

```
$ docker build -t my-apache2 .
$ docker run -dit --name apache -p 80:80 -p 443:443 my-apache2

```

## SSL

docker run --rm httpd:2.4 cat /usr/local/apache2/conf/httpd.conf > my-httpd.conf

edit my-httpd.conf and uncomment

```
#LoadModule socache_shmcb_module modules/mod_socache_shmcb.so
...
#LoadModule ssl_module modules/mod_ssl.so
...
#Include conf/extra/httpd-ssl.conf
...
```

edit and uncomment the line above in Dockerfile and rerun the command
